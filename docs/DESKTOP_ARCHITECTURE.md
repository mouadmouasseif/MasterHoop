# Desktop Architecture

## Options

- PWA Desktop: simplest install path.
- Tauri: preferred candidate for local files, GPU-friendly workflows, and lighter packaging.
- Electron: mature but heavier.

## Direction

Desktop should focus on long video analysis, local file access, exports, and large-screen review workflows.
