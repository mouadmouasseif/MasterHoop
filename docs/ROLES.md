# Roles

BasketMotion AI roles:

- `super_admin`
- `club_admin`
- `coach`
- `athlete`

## Boundaries

Athletes can access their own analyses and training.

Coaches can access assigned athletes through coach-athlete links.

Club admins can access club-scoped players, coaches, teams, reports, and performance.

Super admins can manage platform-level configuration.

Sensitive access is enforced in route guards, permission helpers, Firebase services, and Firebase rules.
